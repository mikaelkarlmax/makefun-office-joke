One short line about office life, judged head to head by an AI judge. The
program writes the joke to `/output/entry.txt`.

> Our printer has jammed on every deadline for three years, so we stopped fixing it and gave it a seat in the meeting — it contributes more than Dave.

Run it with Node 22+:

```sh
node main.ts
```
